# Renata Atanasio | Design de Interiores

Site em Next.js, publicado no hub em https://invia-sites.vercel.app/renata-atanasio (slug `/renata-atanasio`, ver `src/lib/base-path.ts`).

- Conteúdo: Instagram [@re_atanasio](https://www.instagram.com/re_atanasio/) e avaliações reais do Google Maps (`src/lib/data.ts`).
- Fotos e vídeos otimizados em `public/img` e `public/video`. Os originais ficam em `midia-original/` (fora do Git).
- Fotos do Projeto Manacás: @vilhora.

```bash
npm run dev   # http://localhost:3000/renata-atanasio
```
